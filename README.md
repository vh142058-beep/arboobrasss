## 🏛️ Sobre o Projeto

A **ARBO Engenharia & Arquitetura** é especializada na execução de obras residenciais unifamiliares de luxo, retrofits complexos e sedes corporativas de alta representatividade. 

Este projeto foi concebido com uma linguagem visual contemporânea e sóbria, tipografia editorial e código limpo, otimizado para navegadores modernos e dispositivos móveis.

---

## 🚀 Como Visualizar / Testar Localmente

O projeto possui uma versão autônoma pronta em HTML5 puro sem a necessidade de instalar qualquer dependência:

1. Dê um duplo clique no arquivo [`index.html`](./index.html) para abrir diretamente no navegador (Chrome, Edge, Safari, Firefox).
2. Se preferir rodar com um servidor local:
   ```bash
   # Com Python
   python -m http.server 3000

   # Ou com npx
   npx serve .
   ```

## 🌐 Publicação no GitHub Pages (1 Clique)

Para publicar gratuitamente no **GitHub Pages**:

1. Suba este repositório para a sua conta no GitHub.
2. Acesse a aba **Settings** (Configurações) do repositório no GitHub.
3. No menu lateral esquerdo, clique em **Pages**.
4. Em **Build and deployment > Source**, selecione **Deploy from a branch**.
5. Em **Branch**, selecione `main` (ou `master`) e a pasta `/(root)`.
6. Clique em **Save**. O GitHub disponibilizará o link do site no ar em poucos segundos.
